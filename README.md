# BlogSpace · Full Stack Blog Application

A full-stack blogging platform where users can write, edit and share blog posts, comment on them and manage their profile.

## Features

- Sign up and log in with email and password or with Google
- Create, edit and delete posts
- Comments and likes
- Search, a user profile and a personal dashboard
- Contact form

This repository keeps the frontend (React) and backend (Express and MongoDB) files together in one folder. The organised versions are:

- Frontend: [blogspace-1](https://github.com/aksharaagarwal21/blogspace-1)
- Backend: [blogspace-2](https://github.com/aksharaagarwal21/blogspace-2)

## Tech stack

React · Node.js · Express · MongoDB (Mongoose) · Passport.js · JWT
